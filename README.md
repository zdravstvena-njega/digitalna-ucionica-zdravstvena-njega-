# Zdravstvena njega 3 – digitalna učionica

Ovaj repozitorij sadrži statičku web-aplikaciju za učenike trećeg razreda medicinske škole. Trenutno aktivno poglavlje je **Srce i krvne žile**.

## Pokretanje

Otvorite `index.html` ili objavite repozitorij putem GitHub Pages.

Glavna stranica aktivnog poglavlja je `srce-i-krvne-zile.html`.

## Sadržaj

- 10 nastavnih lekcija
- interaktivni simulatori i praktične vježbe
- samoprovjere i završna provjera znanja
- pojmovnik i izvori
- responzivni prikaz za mobitel i računalo
